# Prompts de las imágenes generadas

Las diez piezas se generaron o editaron con la herramienta integrada de
imágenes. Las referencias aportadas se utilizaron únicamente para conservar la
identidad de las personas o definir estilo, composición y ambiente de marca;
ninguna pieza copia una composición existente.
