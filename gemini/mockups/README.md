# Mockups HTML — sandbox

Experimentos de front **aislados**. Cada demo en su subcarpeta:

```
mockups/demo-restaurante/
  index.html
  styles.css
  (imágenes locales o ../../assets/...)
```

## Reglas

- **Una carpeta = un experimento**
- CSS inline o un solo `styles.css` por carpeta
- Sin React, sin npm, sin tocar la raíz del repo
- Abrir con doble clic o `python3 -m http.server` desde la subcarpeta
- Copiar colores de marca: `#050509`, `#29b8ff`, `#8248ff`, `#ff3aa7`

## Antes de “terminar”

Checklist:

- [ ] Se ve bien en celular (375px)
- [ ] Botón WhatsApp visible
- [ ] Imágenes desde `../assets/` o copiadas local
- [ ] Entrega documentada en `../entregas/`

Un dev revisa y adapta — **no copiar directo a producción**.
