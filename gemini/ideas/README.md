# Ideas creativas (solo markdown)

Gemini escribe acá propuestas de:

- Layouts de landing
- Copy para posts
- Paletas alternativas
- Wireframes descritos en texto
- Moodboards en prosa

**Formato sugerido:** `YYYY-MM-DD-tema.md`

Ejemplo de contenido válido:

```markdown
# Demo restaurante — layout propuesto

## Hero
- Foto plato izquierda, título derecha
- CTA: "Pedir por WhatsApp"

## Sección menú
- Grid 3 columnas, cards oscuras
...
```

**No pegar código HTML largo acá** — eso va en `mockups/` si hace falta.
